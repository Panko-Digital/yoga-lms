Interactive Guide / Tutorial Demo

📚 How it works: The interactive guide will automatically appear 20 seconds after page load (for first-time users only). It uses localStorage to remember if you've already seen it.

Quick Start

To enable the guide on any page, simply add this element:

<div class="ylms-guide"></div>

The guide will:

  • Wait 20 seconds after page load
  • Check if the user has seen it before (using localStorage)
  • Show tooltips pointing to important elements
  • Allow users to step through or skip the tutorial

Customizing Guide Steps

Edit the guideSteps array in module-components.js:

var guideSteps = [ { selector: '#modules-link', message: 'Click this to view the full course module and lessons overview', position: 'auto' // auto, top, bottom, left, right }, { selector: '.ylms-pb_circle', message: 'Track your progress through each module', position: 'auto' } // Add more steps as needed ];

Testing the Guide

To test the guide again:

  1. Open browser DevTools (F12)
  2. Go to Console tab
  3. Run: localStorage.removeItem('ylms-guide-completed')
  4. Refresh the page
  5. Wait 20 seconds (or change GUIDE_DELAY_MS in the code)

Features

  • ✅ Automatic positioning (top, bottom, left, right) based on available space
  • ✅ Pointed arrow that points to the target element
  • ✅ High z-index (9999) to appear above iframes and other content
  • ✅ Matches Sanskrit glossary modal styling (blue-dark background, white text)
  • ✅ LocalStorage persistence - won't show again once completed
  • ✅ Skip button to dismiss tutorial
  • ✅ Step counter (e.g., "1 of 3")
  • ✅ Smooth animations and transitions
  • ✅ Keyboard support (Escape to close)
  • ✅ Mobile responsive
  • ✅ Highlights target elements with pulsing animation
  • ✅ Auto-scrolls to bring target elements into view
⏱️ Note: The guide has a 20-second delay. For testing, you can reduce GUIDE_DELAY_MS in the JavaScript file, or use the reset button above and wait.
